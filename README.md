# Broven coffee website

Original supplied React, Vite, Tailwind and Framer Motion template, including all supplied images and video.

## Development

Use Node.js 22. Run `npm ci`, `npm run dev`, `npm run lint`, and `npm run build`.

## Deployment

Repository: https://github.com/reaganmegill-web/creativewebsite

GitHub Pages: https://reaganmegill-web.github.io/creativewebsite/

Vite base: `/creativewebsite/`. Public media use `import.meta.env.BASE_URL`.

The Pages workflow validates and builds before deploying on pushes to `main`, and supports manual runs. In Settings → Pages → Build and deployment, select GitHub Actions as the source.

The supplied template includes placeholder links and decorative ordering/account controls; no commerce backend or coffee quiz was supplied.
